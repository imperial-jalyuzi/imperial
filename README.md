# Imperial Jalyuzi — katalog sahifalari

- `kombo/` — kombo (kun-tun) matolari katalogi: https://imperial-jalyuzi.github.io/kombo/

- Bosh sahifa (imperial-jalyuzi.github.io) kombo katalogiga yo‘naltiradi. Asosiy sayt: https://shamsiddinyusupov.github.io/imperial/
